# Design: 미스터리 숏 — 시작과 끝 북엔드(회귀) + 성장 지표(운영)

**Date:** 2026-05-13  
**Status:** Approved for implementation planning  
**Depends on:** 기존 `prompts/mystery.txt`, `src/script/scriptGenerator.js` 숏 생성 경로

## 문제

- 조회수 일간 변동은 플랫폼 특성상 불가피하지만, **스크립트가 도입부 이미지·디테일과 결말 질문이 따로 놀면** 시청자는 “짧게 두 번 다른 영상”처럼 느끼고 재생·구독 연결성이 약해진다.
- 성장 실험을 하려면 **바꾼 요소를 재현 가능하게** 남기는 것이 좋다(주간 단위 지표).

## 목표 (제품)

1. **북엔드:** 숏 스크립트에서 **첫 1–2문장에 세운 구체적 앵커**(소리, 물건, 장소, 마지막으로 알려진 증거 등)와 **마지막 1–2문장**이 명시적으로 같은 축으로 묶인다. 결말이 새 주제를 갑자기 꺼내지 않는다.
2. **사실 우선:** 기존 FACT-FIRST·키 앵커·연도 규제를 깨지 않는다.
3. **길이:** 기존 단어 상한(`SHORTS_MAX_WORDS`) 및 클램프 로직 유지.

## 비목표

- 롱폼(`mystery-long`) 프롬프트 전면 개편(별도 스펙).
- YouTube Analytics 자동 수집·대시보드(별도 스펙).

## 설계

### 스크립트(숏)

- **도입 HOOK:** 기존처럼 구체적이고 검색 가능한 디테일로 연다.
- **마무리 CLIFFHANGER:** 질문·역설은 허용되나, **반드시 도입에서 드러낸 동일 앵커를 이름·회귀 문구로 되풀이**한다. (표현만 바꾸고 대상은 같아야 함.)
- **금지:** 마지막에만 등장하는 새 인물·새 물건·새 미스터리 축으로 피벗한 뒤, 도입과 무관한 철학적 한 줄로 끝내기.

### 메타데이터(선택·YAGNI)

- 이번 스펙 범위에서는 **`metadata.json`에 새 필드 추가하지 않는다.** 효과 검증은 운영자가 스크립트 텍스트로 수동 확인한다.

### 성장 지표(운영 참고 — 코드 변경 최소)

- **판단 주기:** 업로드 후 **7일 누적** 또는 **주간 합계**를 기본으로 한다. 일간 숫자만으로 스크립트 품질을 판단하지 않는다.

## 테스트·수용 기준

- `prompts/mystery.txt`에 BOOKEND 규칙 문단이 존재한다.
- `generateScript` 사용자 메시지에 BOOKEND 한 줄 보강이 존재한다.
- 선택: 프롬프트 파일에 특정 키워드 존재를 검증하는 경량 테스트 1개.

## 리스크

- 단어 상한 안에서 회귀 문구가 잘리면 의미가 약해질 수 있음 → 모델 지시상 **앵커 단어를 짧게 반복**하도록 유도.
